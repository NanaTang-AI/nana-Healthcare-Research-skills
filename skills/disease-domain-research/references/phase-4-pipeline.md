# Phase 4: Pipeline And Product Opportunities

Read this file only when the request includes pipeline, clinical trials, mechanisms, competitive landscape, target product, or product opportunities.

## Pipeline Retrieval

Search trial registries, regulator databases, company disclosures, conference abstracts, and peer-reviewed publications. Use the registry record as the primary source for study design and current status. Record the retrieval cut-off date because trial status changes.

## Pipeline Table

| Asset | Company | Mechanism/target | Stage/status | Geography | Population and key eligibility | Comparator | Primary endpoint/time point | Key result | Source | Link |
|---|---|---|---|---|---|---|---|---|---|---|

Separate disease activity, symptoms, organ-specific outcomes, steroid reduction, biomarkers, and safety endpoints. Do not compare effect sizes across incompatible designs or time points without qualification.

## Product Population Funnel

Nest the named asset inside the broad disease using these filters:

`broad disease → disease background → organ/phenotype → severity/activity → biomarker/mechanism enrichment → prior treatment → safety/exclusion → practical access`.

State whether each filter is:

- a disease classification axis;
- a trial enrichment criterion;
- a mechanism hypothesis;
- a regulator-approved label criterion;
- a proposed commercial segmentation assumption.

These categories are not interchangeable. In particular, a drug target is not a companion diagnostic unless the trial/label requires it.

## Opportunity Assessment

Evaluate opportunity across:

- patient segment size and ability to identify it;
- current outcome and unmet need;
- mechanism-to-disease rationale;
- clinical differentiation and endpoint relevance;
- safety and monitoring burden;
- route, frequency, site of care, and adherence;
- evidence and regulatory risk;
- reimbursement and access feasibility;
- competitive timing and crowding.

Use an evidence-backed statement for each dimension. Separate facts, interpretations, and assumptions.

## Output Conclusions

End with:

1. the most plausible target segment today;
2. the strongest differentiation hypothesis;
3. the largest evidence gap or failure mode;
4. the next analysis or data source needed to validate the opportunity.
